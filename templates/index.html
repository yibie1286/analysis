    1. Descriptive Statistics

    Mean (Average Score)
    x̄ = (Σ xᵢ) / n

    xᵢ = individual response value  |  n = number of respondents
    Computed per item (e.g. SD1, TQ2) and per dimension (average of all items in that group).

    Standard Deviation
    s = √[ Σ(xᵢ − x̄)² / (n − 1) ]

    Sample standard deviation (Bessel's correction, n−1 denominator).
    Measures spread of responses around the mean. Higher value = more disagreement among respondents.

    2. Customer Satisfaction Index (CSI)

    Dimension Mean Score
    Mean_dim = (Σ all item scores in dimension) / (k × n)

    k = number of items in the dimension  |  n = number of respondents

    CSI per Dimension
    CSI (%) = (Mean_dim / 5) × 100

    Scales the mean score (1–5) to a percentage (0–100%).
    A score of 5 = 100% (maximum satisfaction).

    Overall CSI
    Overall CSI (%) = (Mean of all dimension means / 5) × 100

    Simple average across all five dimensions (SD, TQ, PP, COM, SAT).

    Interpretation Scale
    CSI RangeInterpretation
    80% – 100%Very Satisfied
    60% – 79%Satisfied
    40% – 59%Neutral
    < 40%Dissatisfied

    3. Reliability Analysis — Cronbach's Alpha

    Cronbach's Alpha (α)
    α = (k / (k − 1)) × (1 − Σσᵢ² / σ²_total)

    k = number of items in the scale
    Σσᵢ² = sum of individual item variances
    σ²_total = variance of the total (sum) score across all items

    Measures internal consistency — how closely related the items in a dimension are.

    Interpretation Scale
    Alpha (α)Interpretation
    α ≥ 0.9Excellent
    0.8 ≤ α < 0.9Good
    0.7 ≤ α < 0.8Acceptable
    0.6 ≤ α < 0.7Questionable
    α < 0.6Poor

    4. Multiple Linear Regression

    Regression Model
    SAT = β₀ + β₁·SD + β₂·TQ + β₃·PP + β₄·COM + ε

    SAT = mean Customer Satisfaction score (dependent variable)
    SD, TQ, PP, COM = mean dimension scores (independent variables)
    β₀ = intercept (constant)
    β₁–β₄ = regression coefficients (effect size per unit increase)
    ε = error term

    Coefficient of Determination (R²)
    R² = 1 − (SS_res / SS_tot)

    SS_res = Σ(yᵢ − ŷᵢ)² — residual sum of squares
    SS_tot = Σ(yᵢ − ȳ)² — total sum of squares
    Proportion of variance in SAT explained by the predictors. Range: 0–1.

    Adjusted R²
    Adj. R² = 1 − [(1 − R²)(n − 1) / (n − k − 1)]

    n = number of observations  |  k = number of predictors
    Penalizes for adding non-informative predictors. Preferred over R² for model comparison.

    F-Statistic (ANOVA)
    F = (SS_reg / k) / (SS_res / (n − k − 1))

    Tests whether the overall model is statistically significant.
    If p < 0.05, the model explains a significant portion of variance in SAT.

    t-Statistic (per coefficient)
    t = βᵢ / SE(βᵢ)

    SE(βᵢ) = standard error of the coefficient
    Used to test whether each predictor's coefficient is significantly different from zero.
    A predictor is significant if its p-value < 0.05.

    OLS Estimation (Ordinary Least Squares)
    β̂ = (XᵀX)⁻¹ Xᵀy

    X = design matrix (predictors + intercept column)
    y = response vector (SAT scores)
    Minimizes the sum of squared residuals: Σ(yᵢ − ŷᵢ)²

    5. Pearson Correlation

    Pearson Correlation Coefficient (r)
    r(X,Y) = Σ[(xᵢ−x̄)(yᵢ−ȳ)] / √[Σ(xᵢ−x̄)² · Σ(yᵢ−ȳ)²]

    Measures the linear relationship between two dimension scores. Range: −1 to +1.
    r > 0.7 = strong positive  |  0.4–0.7 = moderate  |  < 0.4 = weak  |  r < 0 = negative relationship

    6. Net Promoter Score (NPS)

    NPS Segmentation
    ScoreSegment
    9 – 10Promoters
    7 – 8Passives
    0 – 6Detractors
    NPS Score
    NPS = ((Promoters − Detractors) / Total respondents) × 100

    Range: −100 to +100.
    NPS > 50 = Excellent  |  0–50 = Good  |  < 0 = Needs improvement
